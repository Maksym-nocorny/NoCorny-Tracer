# NoCorny Tracer — іконка v2 (напрям D5)

Побудовано з фігма-файла `ON7LgVKrIHcmHUTCElXEP5`, сторінка **🖲 Icon Lab**,
секція **🎯 Icon System — фінал (D5)**. Джерело правди — компоненти в цій секції.

## Геометрія

Тінь холодна, `#1B2430` — з теплою коричнюватою білий однаково тягнув у жовтизну.

Сітка Apple для macOS: полотно **1024**, плашка **824×824** з відступом 100 по колу,
радіус **185.4** зі згладжуванням кутів 0.6 (справжній squircle, не просто заокруглення).

- плашка — `#FCFCFD → #ECEDF0` (холодний білий: верх чистий білий, сірий заходить
  лише у тіньовий кінець градієнта)
- рамка — 8 штрихів `#3E90FF`, намальованих ЯВНИМ вектором по осьовій лінії скругленого
  квадрата: по два на чверть контуру, кожен заходить за ріг. `dashPattern` тут не годиться —
  Figma сама нормалізує пунктир під ціле число циклів і позиції стають некерованими
- знак — `#0B5BE0 → #0846B5`, центроїд трикутника стоїть рівно в центрі полотна
- крапка — `#F2584F → #CE3B33`, діаметр 106, сидить у відкритому верхньо-лівому куті

## Малі розміри — окреме креслення

16 і 32 не є зменшеним майстром: у 16 px штрих завтовшки 30/1024 перетворюється на шум.

| розмір | джерело |
|---|---|
| 16 | `Icon / Small 16` — без рамки, більший знак і крапка |
| 32 | `Icon / Small 32` — чотири товсті штрихи замість восьми |
| 64 і вище | `Icon / Master — Light` |

## Меню-бар

Той самий пунктир і той самий знак, що в іконці застосунку — але **накреслені окремо
в натуральних 22×22**, а не зменшені з майстра.

Два уроки, за які довелось заплатити переробкою:

1. **Малювати треба одразу в цільовому розмірі.** Перша спроба була в масштабі ×8 із
   подальшим зменшенням — на цьому кроці все з'їхало на півпікселя: обведення
   розмазувалось на три ряди замість двох, верхні штрихи ставали на 7, нижні на 8.
2. **Растеризувати теж треба одразу туди.** Експорт у 176 px і `sips` до 22 дає той самий
   зсув. Правильно — тримати компонент 22×22 і брати експорт зі `scale` 1 / 2 / 3.

Сітка: рамка 18 px @ (2,2), обведення 2 px, вісім штрихів 3×2 px на позиціях 6 і 13
по кожній грані. Знак — 8×10 px, видимі межі 7..15 і 6..16. Усе на цілих пікселях,
жодного згладжування на штрихах.

**Стан запису замінює трикутник червоним колом** 8×8 px у центрі рамки. Не крапка збоку —
саме коло замість знака відтворення, бо це і є класична кнопка запису.

| файл | де застосовується |
|---|---|
| `menubar/v2/idle-dark*.png` | спокій, світла тема |
| `menubar/v2/idle-light*.png` | спокій, темна тема |
| `menubar/v2/rec-dark*.png` | запис, світла тема |
| `menubar/v2/rec-light*.png` | запис, темна тема |
| `menubar/v2/idle-template*.png` | чорний template — систему інвертує сама |

Кожен у трьох щільностях: 22 / 44 / 66 px, кожен окремо растеризований.

**Як підключати.** Для спокою достатньо `idle-template` з `isTemplate = true` — macOS
сама перефарбує його під тему і під підсвічений пункт меню. Явна пара `idle-dark` /
`idle-light` потрібна, лише якщо керуєш кольором самотужки. Для запису template не
годиться (він монохромний і з'їсть червоне) — там бери `rec-dark` / `rec-light`
за поточною темою, з `isTemplate = false`.

Стара трійця кандидатів A/B/C лишилась у `menubar/_alt/` як історія.

## Локап — знак із назвою

Гарнітура **Space Grotesk**. «NoCorny» — Light, приглушений сірий; «Tracer» — Bold, синій.
Трекінг −2%. Материнський бренд відступає, назва продукту веде.

| | світла тема | темна тема |
|---|---|---|
| NoCorny | `#9AA1AD` | `#8A93A3` |
| Tracer  | `#0B5BE0` | `#3E90FF` |

Три компоновки: **горизонтальна** (основна), **компактна** (той самий рядок, але зі стягнутим
знаком — для дрібних розмірів і вузьких місць) і **вертикальна** (сплеш, сторінка застосунку).

Уся геометрія прив'язана до капітальної висоти, а не до кегля: знак — 1.30 капітальної,
проміжок до назви — 0.62, між словами — 0.34. Тому локап масштабується цілим шматком
і не «розповзається» на інших розмірах.

**Знак у локапі має два яруси.** Повний, із пунктирною рамкою, живе у великих розмірах.
Від приблизно 20 px рамка перетворюється на пил — там працює компактний знак:
трикутник із притуленою крапкою запису. Це та сама логіка, що й у 16/32 px іконки.

| шлях | що це |
|---|---|
| `lockup/horizontal-{light,dark}.svg` | основний локап, вектор |
| `lockup/compact-{light,dark}.svg` | компактний, для дрібного |
| `lockup/stacked-{light,dark}.svg` | вертикальний |
| `lockup/*@2x.png`, `*@3x.png` | растр із прозорим тлом |
| `lockup/proof-sheet.png` | контрольний аркуш локапа |
| `svg/mark-dark.svg` | знак без плашки, темна тема |
| `svg/mark-compact-{light,dark}.svg` | компактний знак |

## Як поставити в застосунок

```
cp -R design/icon-v2/AppIcon.appiconset/. Sources/NoCornyTracer/Assets.xcassets/AppIcon.appiconset/
```

Іконку меню-бару Swift підхоплює як `NSImage(named:)` з `isTemplate = true`.
